Glow Beauty | Makeup Store

Glow Beauty is a modern and elegant makeup website designed for beauty lovers. It showcases a variety of makeup and beauty products, including lipsticks, makeup sets, and skincare essentials. The website features a beautiful pink and cream color theme, an attractive homepage, product cards, prices, and easy navigation. It is developed using HTML and CSS with a responsive layout for desktop and mobile devices. The main goal of Glow Beauty is to provide an attractive online shopping experience and help customers discover their favorite beauty products.

Technologies Used: HTML5, CSS3

Key Features:

Attractive and modern design

Beauty product showcase

Product prices and shop buttons

Responsive layout

Easy navigation

Elegant pink and cream theme
